# Pending Definitions (확정 전 방향)

아래 항목은 정의 방향은 잡혔으나 소스 스키마 확인 후 최종 연결(wire)이 필요했던 지표들이다.

| 카드 | 정의 방향 | 소스 후보 |
|---|---|---|
| 임박할인 전환율 | 임박할인 경유 구매자 / 전체 구매자 | closeout(임박할인) 대시보드 |
| M+1 리텐션 | 첫구매 코호트의 M+1 재구매율 | 월별 코호트 마트(리텐션 컬럼 식별 필요) |
| 채널믹스 | 채널별(퍼포먼스/CRM/제휴) 기여주문 / 총주문 | 채널 기여 대시보드 (그레인 확인 필요) |
| CRM 발송 추세 | 발송수/캠페인수 추세 | CRM 발송·캠페인 대시보드 |
| 신규가입 | 가입일 = 기준일인 회원 distinct count | 고객 마스터(비용 가드 필요) |
| 쿠폰예산 소진율 | 소진율 = 누적사용액 / 월예산(분모) | 계획 시트 미러링 (분모 트랙) |
| 카테고리 성과 / 침투율(PNTR) | 단일 스칼라가 아닌 분해 뷰 | 카테고리·세그 분해 뷰 |

# Change Log

- **채널믹스 지표**: 채널별 기여주문 데이터가 최근 구간에 적재되지 않아(≈0), 대체 소스로의 재소싱을 시도했으나 헤더 없는 원시 덤프 형태라 구조화(파싱) 작업이 선행되어야 연결 가능한 것으로 확인됨. 현재는 표출에서 제외.
- **K1 센터 구분 매핑**: 배송유형 기준 소스에는 센터 구분 컬럼이 존재하지 않아, PDF 등 별도 자료의 센터 코드 매핑을 그대로 가짜로 대입하는 것을 금지하고 별도 센터 그레인 소스가 필요함을 명시함.
- **월 달성률 분모 정정**: 달성률 계산 시 분모를 "월 전체 계획"이 아니라 "동일 경과일 기준 누적 계획"으로 정정함(월초 구조적으로 낮게 나오는 오류 교정).
- **구매전환율(W030) 정의**: 분자(구매자)는 플랫폼별로 분해하지 않고 전사 헤드라인으로 표기하며, 분모(DAU)만 플랫폼(앱/모바일웹/PC웹)별로 분해함. 분자를 임의로 분할 추정하지 않는다는 원칙을 명시.
- **월 코호트 지표의 주간 비교 부적합**: 월 누적 기준 지표를 일별 전주(WoW) 비교에 쓰면 분모(월누적)와 분자(일별 플로우)의 스케일이 맞지 않아 부적합함. 월그레인 지표는 전월/전년 기준으로 비교해야 한다.
- **비교 지표 단위 규칙**: 비율(%) 단위 지표의 증감은 %p(절대차)로, 금액·건수 지표의 증감은 %(상대변화)로 표기한다. 기준값이 없으면 비교값을 표기하지 않는다(임의 추정 금지).
