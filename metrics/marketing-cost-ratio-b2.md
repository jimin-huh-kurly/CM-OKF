# Definition

**B2(마케팅 비용률) 분자** = CRM 쿠폰 사용액 + 제휴 쿠폰 사용액 + 뷰티 쿠폰 사용액(핵심 3종). **분모** = GMV2.

B2 분자에서 제외되는 쿠폰(ARPU 목적·멤버십·러버스·CRM 외부광고 성과 쿠폰 등)은 절대액을 별도 라인에서 추적하며, 이는 B2 산식에서 빠졌다고 해서 비용이 누락된 것은 아니다.

# Coupon Classification Map

쿠폰은 권한 주체(누가 발행을 결정하는가) 기준으로 아래와 같이 분류되고, 각각 다른 관리 지표로 귀속된다.

| 권한 주체 | 쿠폰 분류 | 발행 사유 | 귀속처 |
|---|---|---|---|
| 마케팅 | CRM 쿠폰 / 제휴 쿠폰 / 뷰티 쿠폰 | CRM / 제휴 / 뷰티 | B2 분자 |
| 마케팅 | ARPU 쿠폰 / 러버스 쿠폰 / CRM 외부광고(퍼포먼스) 쿠폰 | ARPU / 러버스 / 외부광고 | 별도 라인 추적(B2 제외) |
| 마케팅/구독 | 멤버십 쿠폰 | 유료구독 무배송/혜택 | 구독원가(별도 수익성 항목) |
| 운영 | 캐파(수요조절) 쿠폰 | 매출 제고 | 캐파/운영 제약 지표(K2) |
| 커머스/MD | MD요청 브랜드/구좌 쿠폰(프로모션 포함) | MD요청/프로모션 | 상품/커머스 쿠폰 |
| 커머스/MD | 카드사 분담 쿠폰(일반/컬리카드 전용) | MD요청 | 상품/커머스 쿠폰 |
| 상품 | 상품 프로모션 쿠폰 / 상시가격대응 쿠폰 | 상품 프로모션/가격대응 | 상품할인(B1) |
| 신사업 | 컬리나우 초회차 쿠폰 | 컬리나우 신규 | 신사업 별도 관리 |

"프로모션 쿠폰"은 단일 컬럼으로 존재하지 않으며 MD요청 브랜드 쿠폰군에 포함되어 있으므로, 분리해서 보려면 발행사유가 '프로모션'인 것만 별도 집계해야 한다.

# Change Notes

- 쿠폰통합 정의 정직화(2026-06-19): 쿠폰 부담은 전사 GMV가 아니라 해당 쿠폰이 실제 사용된 거래의 GMV(VAT 제외) 대비 컬리 분담액으로 계산한다. 효율은 EM%(공헌이익률 계열)로 본다.
- ARPU 목적 쿠폰(발행사유2='ARPU')의 컬리 분담률은 별도로 추적한다(2026-06-23).
